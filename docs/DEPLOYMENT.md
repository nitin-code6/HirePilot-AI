# Deployment Guide

HirePilot AI is production-ready for multi-cloud deployments:
- **Frontend**: Vercel / Netlify / Cloudflare Pages.
- **Backend API & MCP Server**: Render / Railway / AWS ECS / Google Cloud Run.
- **Database**: PostgreSQL on Neon / Supabase / AWS RDS.
- **Cache**: Redis on Upstash / Redis Cloud.
- **Containers**: Multi-stage Dockerfiles and `docker-compose.yml`.
