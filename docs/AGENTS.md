# Multi-Agent Architecture

## LangGraph Supervisor Model
The supervisor analyzes HR manager prompt intents, maintains structured dialogue state, and routes work to specialized domain agents:
1. **Job Management Agent**: JD generation, requirements tuning, publishing preparation.
2. **Resume Screening Agent**: Text extraction, deterministic matching, skill gap analysis.
3. **Candidate Management Agent**: Profile tracking, lifecycle stage transitions.
4. **Interview Agent**: Calendar availability resolution, slot recommendations.
5. **Communication Agent**: Contextual email draft generation and preview.
6. **Analytics Agent**: Real-time hiring funnel and conversion analytics.
