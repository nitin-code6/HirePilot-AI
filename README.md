# HirePilot AI — Your AI Co-Pilot for Smarter Hiring

HirePilot AI is an enterprise-grade AI-powered recruitment management platform designed for modern HR teams. It pairs an autonomous multi-agent recruitment architecture (LangGraph + MCP SDK) with a full-featured React 19/Vite frontend and FastAPI backend.

## Architecture Highlights
- **Supervisor-Led Multi-Agent System**: LangGraph supervisor dynamically routes HR requests to Job, Resume Screening, Candidate, Interview, Communication, and Analytics agents.
- **Model Context Protocol (MCP)**: Standards-compliant MCP server exposing recruitment tools.
- **Human-in-the-Loop (HITL)**: Enforced approval gates for job publication, email dispatch, interview scheduling, and pipeline status changes.
- **Explainable Screening Engine**: Deterministic candidate qualification matching with skill gap analysis.
- **Enterprise SaaS Dashboard**: Navy & Indigo design system built with Tailwind CSS, Lucide icons, and Recharts.
